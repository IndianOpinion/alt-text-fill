# Security policy

## Reporting a vulnerability

Please report security problems privately to **hello@indianopinion.org**,
not in a public issue. Include the version, what you found, how to
reproduce it, and what an attacker could do with it.

We acknowledge reports within 3 working days and aim to give a first
assessment within 7 days. A fix for a confirmed problem is released as
soon as it is ready, normally within 30 days, and credited to you unless
you prefer otherwise.

## Supported versions

| Version | Supported |
|---|---|
| 0.1.x | Yes |

## Scope

Of particular interest: a way to write alt text without approval, to
bypass a capability or nonce check, to read an API key, to make the
remote fetcher reach a host outside its allow list, to inject HTML or
script through a suggestion, or to make the plugin spend past its caps or
kill switch.
